Hosen 3.0 Android App — Starter Project

এটি একটি Native Android App-এর Android Studio source project।

যা আছে:
- Native Kotlin + Jetpack Compose UI
- Home, YouTube, Stories, Projects, Contact ট্যাব
- Hosen 3.0 ওয়েবসাইট ও YouTube চ্যানেলের লিংক
- Dark theme ও mobile-friendly navigation

গুরুত্বপূর্ণ:
- এটি Android Studio project; তৈরি APK ফাইল নয়।
- APK বানাতে কম্পিউটারে Android Studio ইনস্টল করে এই ফোল্ডারটি Open করতে হবে।
- Gradle sync শেষ হলে Build > Build Bundle(s) / APK(s) > Build APK(s) নির্বাচন করুন।
- APK তৈরি হলে Android Studio-এর Build output থেকে ফাইলটি পাওয়া যাবে।
